# Reusable templates

Copy a template into the relevant week, rename it and replace the prompts with your own work. Keep these originals blank for reuse.

| Template | Where to use it |
| :--- | :--- |
| [Learning note](note-template.md) | `week-XX/notes/topic-name.md` |
| [Exercise](exercise-template.md) | `week-XX/exercises/exercise-name/README.md` |
| [Project](project-template.md) | `week-XX/projects/project-name/README.md` |

Keep related scripts, notebooks, workbooks and images beside the exercise or project README. Link the finished item from the weekly overview; remove any template sections that do not apply.
